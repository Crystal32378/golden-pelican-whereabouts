3. 這個世界的四條家規（GPT Sol 訂，Opus 實作）

  1. 一片羽毛走天下 — 所有東西都是同一個幾何形拉長、壓扁、換顏色
  2. 一顆多面體走天下 — 身體、石頭、雲、鴿子都是同一種切面
  3. 不准光滑曲面 — 每個面各自受光，所以看起來像剪紙
  4. 顏色平塗 — 沒有照片、沒有雜訊材質

分店也照這四條做：正經的世界地圖（容器）＋ 荒謬的內容（一隻鵜鶘在騎車）＝ 這就是笑點。

4. 五分鐘練習：親手加第 23 站

  1. 打開 index.html，找到第 126 行（兔子洞那一行）
  2. 複製整行，改四個地方：id（要跟主站的錨點一樣）、中英文名字、經緯度（不知道就填 null,null，它就會自己進「無法定位的地點」）、兩種語言的案情報告
  3. 把照片命名成 id.png 丟進 postcards/
  4. 重新整理瀏覽器

你會發現：你剛剛做的所有事（點菜 → 蓋 → 實測 → 修 → 上線）就是這個練習的完整版——用 AI 蓋網站的實際工作內容是「決定內容、驗收、修正」，不是寫程式。
