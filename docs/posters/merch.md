# 周邊商品照（鄉民版）· 8 件

**這不是識別系統，這是路邊攤。**

分店／主站那套鎖死的 SVG mark 拿來這裡是錯的 —— 那是「品牌部門精心制定」的語氣。
這裡的規則只有底層四件事，違規就是違規：

1. **紅色系**為主（單車紅、布章紅、印章紅）
2. **舊公文紙／自行車文化**（卷宗、印章、布章、水壺、帆布）
3. **一隻鵜鶘**（畫法隨人，長得不像隨他）
4. **案件編號** ＋ **一本正經的官僚語氣**

其餘全部放任民間變形。以下八件是八個不同的人做的，**彼此不知道對方存在**：

| | 做的人 | 他堅信的版本 |
|---|---|---|
| MK-01 | 布章廠 | 圓徽＝一個輪子＋站在上面的鳥 |
| MK-02 | 印章店 | 只要一個章，寫 FILE CLOSED |
| MK-03 | 帆布行 | 整台腳踏車，鳥騎在上面 |
| MK-04 | 別針廠 | 只有一個輪子，因為他只記得輪子 |
| MK-05 | 帽廠 | STILL AT LARGE，別的不會畫 |
| MK-06 | 水壺廠 | 24 PLACES · NO PERMIT，句子而非圖 |
| MK-07 | 貼紙廠 | 把 GP-001 當圖案本身 |
| MK-08 | 裝訂廠 | 鳥要低頭看地，因為牠在找洞 |

> 為什麼要放任：都市傳說的視覺系統就是這樣 —— **每個人都看過牠，每個人畫的又不太一樣**。
> 一致到一個百分點，就變成官方了；那不好玩，而且那不是這個故事。

## 鎖定的 DNA（只有這五樣）

不管誰做的、做到第幾件，下面五樣不能動。**其餘全部放任變形。**

| # | DNA | 為什麼不能動 |
|---|---|---|
| 1 | **鵜鶘** | 一隻長腳的鳥。看起來像鵜鶘就行，不用真的像 |
| 2 | **輪子／自行車** | 單車是牠為什麼會到 24 個地方的原因 |
| 3 | **紅色系** | 單車紅、布章紅、印章紅 —— 全站的命脈 |
| 4 | **案件感** | 案件編號、公文、證物。沒有案件感就只是插畫 |
| 5 | **一本正經地胡鬧** | 措辭必須像公文，內容必須很荒唐。這兩者同時成立才叫這個世界 |

### 容許的變形（這些**不要**修）

- 有人只畫一個輪子 ✅
- 有人畫整台腳踏車 ✅
- 有人畫不出鳥，改寫字 ✅
- 輻條數目不一、輪子大小不一 ✅
- 有人在角落蓋一個不明意思的章 ✅

### 明令禁止

- 不要水印、不要浮水印 logo、不要網址
- 不要 glossy 3D render、塑膠感、卡通、可愛、商業廣告風
- 不要把不同作品「統一」成同一個 LOGO —— **那是這一頁唯一的失敗**

## 通則（八張都適用）

- 比例 **3:4**（1152×1536）
- **主體一律是照片**，不是白底排版。要有布的纖維、紙的纖維、玻璃的反光。
- **質感來自物理**：摺痕、磨損、縫線不勻、雨漬、刮痕、邊緣起毛 —— 不要叫模型「畫舊一點」
- **資訊文字全英文**；除列出的文字外不得出現任何其他文字
- 每張都應該看得出是**別人在店裡隨手做的**，不是工廠輸出

## 01｜布章（embroidered patch · 後宮側面）

```

denim jacket shoulder, outdoors in late afternoon light against a harbour wall.

The patch is a circle about six centimetres across with a red stitched border and one
loose thread escaping at the top right. Stitched inside in cream, red and black thread,
very unevenly, by somebody working from memory rather than from a template: a bicycle
wheel seen from the side, and standing on top of it a long-legged bird with its wings
level. The stitching is not accurate. Two spokes are missing and the bird's beak is a
little too long. That is how it was made.

The roundel contains no lettering of any kind. The only thread is stitch.

The jacket canvas is faded, with a small darn in darker thread at the shoulder seam and
a scatter of pale lint.

No text anywhere. No watermark, no logo, no website.
```
