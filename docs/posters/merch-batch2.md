# 周邊商品照 · 續篇 MK-21～MK-26（6 件）

延伸 `merch.md` 的第二批。**同樣的邏輯：六個不同的人做的，彼此不知道對方存在。**
風格 DNA、比例、質感原則、禁止事項全部沿用 `merch.md`，這裡不重複，只補新的。

## 為什麼是這六件

第一批（MK-01～20）已經用過：布章、印章、帆布、帽、水壺、貼紙、單車、書籤、鑰匙圈、磁鐵、抱枕、T恤…
這一批刻意挑**沒有人做過的載體**，並且每件來自不同的城鎮、不同的手藝。
「一時看不出是同一個人做的」比「畫得好看」重要。

| # | 做的人 | 他堅信的版本 |
|---|---|---|
| MK-21 | 停在月台的剪鐵站 | 只有一個輪子，焊在鐵皮上，其他都不必畫 |
| MK-22 | 早餐店的老闆娘 | 蛋餅上壓一個紅色單車圖樣，旁邊蓋「無照騎乘」 |
| MK-23 |  fishing  tackle 店（漁具店） | 浮標做成鳥的形狀，紅色，鉤子當單車輪 |
| MK-24 | 修鞋匠 | 鞋跟釘上一枚小銅牌，只寫 GP-001，不解釋 |
| MK-25 | 冰菓室 | 刮鬆的糖霜上用醬油畫了一隻鳥，旁邊寫「本日特約」 |
| MK-26 | 寺廟的文青 | 紅色棉線綁在香灰上，打一個結，結上垂一張小紙條 |

> MK-26 是唯一一個把「拜」跟「案件」混在一起的。這是這個世界觀本來就有的幽默，不修。
